三、整理方案：三梯队，按风险从低到高

下次用到会重新下载
4Temp 临时文件1.71 GB 清 C:\Users\52400\AppData\Local\Temp 里的内容
正在被占用的会跳过，正常
5回收站1.14 GB 右键回收站 → 清空

第二梯队 迁移到 D 盘 —— 低风险，约省 14.4 GB

这三项都是"数据跟着软件走"，软件本身不动，只改数据存放路径。D 盘有 189.5 GB，随便放。

#搬什么能省怎么搬（在软件设置里改，别手动剪切）
1微信聊天文件4.64 GB 微信 → 设置 → 文件管理 → 更改存储位置 → 选 D:\微信文件
改完微信会自己搬，别手动动文件夹
2企业微信文件6.53 GB 企业微信 → 设置 → 通用 → 文件存储位置 → 改到 D:\WXWork

为什么必须用软件自己的设置改：手动剪切文件夹，软件的索引/数据库路径还指着 C 盘，会报错或者重新下载一遍。从设置里改，软件会自己迁移并更新路径。

第三梯队 系统级调整 —— 需管理员权限，约省 13–19 GB

#调什么能省怎么做 + 代价
1关闭休眠（hiberfil.sys）6.29 GB 管理员 CMD 执行 powercfg /h off
⚠ 代价：不能用"休眠"，且"快速启动"会失效（开机慢几秒）。如果你用笔记本合盖休眠，别关。
2虚拟内存搬 D 盘 / 缩小7–8 GB 系统属性 → 高级 → 性能设置 → 高级 → 虚拟内存 → 更改 → C 盘设为"无分页文件"，D 盘设 8192–16384 MB
⚠ 代价：D 盘如果是机械硬盘，会略慢。SSD 就无所谓。
3DISM 清理 WinSxS1–5 GB 管理员 CMD：DISM /Online /Cleanup-Image /StartComponentCleanup /ResetBase
⚠ 代价：执行后无法卸载已安装的更新（回滚不了）。系统稳定的话没问题。耗时 10–30 分钟。
4系统还原点视情况 系统保护 → 配置 → 限制最大使用量到 3–5%
保留最近的还原点，删更早的
小计≈ 13–19 GB建议只做 1 和 3，2 看你 D 盘是不是 SSD

六、顺手发现的两个"隐形浪费"

1. Chrome 内置 AI 模型占 3.98 GB

AppData\Local\Google\Chrome\User Data\OptGuideOnDeviceModel —— 这是 Chrome 的端侧 AI 模型（Gemini Nano），给"帮我写"之类的功能用的。

如果你不用 Chrome 的 AI 功能：Chrome 设置 → 搜索"AI" → 关闭相关选项，然后删掉这个文件夹，直接省 3.98 GB。

注意：Chrome 更新后可能会重新下载。关掉设置就不会。

2. 豆包（Doubao）4.32 GB，装了可能在后台堆数据

AppData\Local\Doubao 4.32 GB + DoubaoWork 0.72 GB = 5.04 GB。如果你不常用，可以考虑卸载或者清缓存。

顺便：WPS 4.74 GB 里也有大量备份文件，可以在 WPS 设置里清"备份中心"。

八、想长期不再紧张，做这三件事

  1. 改默认下载目录到 D 盘：浏览器设置 → 下载 → 位置改成 D:\下载。这一步能长期防止 Downloads 再堆 3 GB。
  2. 把工作文件放 D 盘：你现在 `D:\个人知识库`、`D:\工作文件夹` 已经很规范，继续保持。C 盘只放系统和软件。
  3. 每月扫一次：这份清单我可以在每月最后一天提醒你跑一遍，第一梯队那 8 项 20 分钟搞定。
