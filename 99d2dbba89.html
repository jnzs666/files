今天重点 ① · 知识 / 蒸馏
sametbrr/llm-wiki-manager　★72

它实现的正是 Karpathy 的 LLM Wiki 模式，跟你现在这套知识库是同一个路数：你只管往 raw/ 里放资料，Agent 独占 wiki/ 层，把资料编译成互链页面。

两个细节值得借鉴：「更新」不是改一处，而是全库语义扫描——一条修正要找遍所有转述过它的页面，逐个确认后再统一改；两个来源打架时不覆盖，双版本共存并标注来源。随包 5 个幂等脚本（初始化、追加日志、更新索引、体检、版本迁移），纯 Python 标准库，Python 3.9+ 即可，不用 pip 装任何东西。

注意：仓库很新、星标只有 72，没有大规模验证；README 也没有正式的操作系统支持矩阵，跨平台只是推断。安装可以走手工复制技能目录，不必引入整个插件市场。

https://github.com/sametbrr/llm-wiki-manager
今天重点 ② · 视频蒸馏
brenoepics/video-to-skill　★149

原来「书 → 技能」已经跑通，这个是「视频 → 技能」：给一个 YouTube 链接或本地视频文件，它把旁白转写、按画面变化切镜头、逐帧读屏幕上的命令，写成带时间戳出处的操作步骤，再放到系统沙箱里真跑一遍，通过才允许安装。

关键设计是读画面而不是只听转录。官方举的例子很说明问题：Excel 教程里旁白被听成「some」，画面里清清楚楚是 =SUM(B3:B10)。另外同主题喂第二个视频会增量合并，两版说法冲突就都留作带出处的变体，而不是覆盖。

注意：Windows 原生支持是 11 月 2 日刚加的，只上线两天；首次使用会下载 ffmpeg、yt-dlp 和语音模型（下载清单先给你看、按指纹校验），不需要 API Key，但要本机有能跑 Agent 的客户端。先用一条短的、画面清晰的软件操作视频试，别拿长课。

https://github.com/brenoepics/video-to-skill
