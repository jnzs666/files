私域负责人 · JD 优化版

2026-10-30 ｜ 方向：客服优化 → 下单转化 → 私域沉淀 → 复购（器械 + 课程）

本版基于我方实际业务数据设计 KPI，非通用模板

一、先说三个判断：这个岗为什么难招

判断 1｜这不是"私域运营"，是三件事捆在一起

你说的链路是：客服优化 → 引导下单 → 转化私域 → 私域复购（产品+课程）。这其实是三种能力：

能力市面上这类人通常缺什么
客服管理会排班、会处理投诉、会盯响应时长不会从对话里挖商机，习惯被动响应
销售转化会逼单、会讲卖点不习惯做服务，一开口就硬推，反而掉好评
私域运营会拉群、会发券、会做活动不懂专业产品，讲不清"空气波怎么用""DMS 和筋膜枪的区别"
关键：我们卖的是康复器械和课程，不是快消品。

客户问"我这个腰突能用吗""做完手术多久能上"，只会发券的人接不住这种对话。所以这个岗必须是"懂一点专业 + 会做服务 + 能转化"的人，而不是纯私域运营。

"我们要的不是把客户拉进群的人，
是能听懂客户说'我腰疼'，然后判断他该买什么、该学什么的人。"

判断 2｜最大的机会不在"复购"，在"器械 × 课程的交叉"

你现在想的是"私域内做复购、买产品、课程"。但真正的杠杆在这儿：

买康复器械的人，本身大概率就是康复从业者或深度爱好者 → 他们极可能是课程的客户。

看我们的盘子：空气波月销 133.4 万（占一类电商 29%），这些人里有多少是康复师、治疗师、健身教练？而运动康复师课程目标是 562.4 万、线下课 787.7 万——两者现在是完全割裂的。

反过来说，学课程的人也需要器械（他们回去要练、要教学）。这条链现在没人接。

所以 JD 里我会明确写：私域的第一优先不是"再卖一次同一台机器"，是"把器械客户转成课程客户，把课程客户转成器械客户"。

判断 3｜这个岗的第一价值可能是"降退款"，不是"增收"

指标现状（9月）说明
一类电商退款率17.79%月净销 461.4 万
二类电商退款率31.41%GSV 35.1 万，近三分之一退掉
空气波毛利率44.9%低于大盘 48.96%
为什么这点重要：私域 GMV 从 0 起，第一年做不出大数；但退款率每降 1 个百分点，是纯利润——不用多花一分推广费。

二类电商 31.41% 的退款率，说明买的人不知道自己买了什么、不会用、或者预期不符。这恰恰是客服+内容能解决的问题，也是这个岗最容易出成绩的地方。

"别一上来就考私域 GMV。
第一年真正该考的是：退款率降多少、加微率多少、首单转化多少。"

二、优化后的 JD（正式版）

私域增长负责人（客服转化方向）

汇报对象：执行副总（陈嘉男）｜工作地点：郑州｜薪资：面议（结构见第五节）

岗位定位

负责把「客服」从成本中心改造成利润中心：在服务过程中识别需求、引导下单，把客户沉淀到私域，在私域内完成器械复购 + 课程转化。

你要做的事（按优先级）

  1. 重构客服体系（0-3 个月）
    梳理现有客服 SOP，把"被动应答"改成"主动引导"：设计话术分层、建立需求识别清单（什么话术代表什么需求）、优化售前咨询到下单的转化路径。目标：把退款率和差评率降下来。
  2. 建立加微转化机制（1-4 个月）
    设计"为什么客户愿意加微信"的理由（不是发券，是提供持续价值：使用指导、康复知识、售后跟踪），把平台客户沉淀到企业微信。目标：加微率和首单转化率。
  3. 私域内容与运营体系（2-6 个月）
    按客户类型分层（术后康复 / 运动损伤 / 职业从业者 / 家庭用户），匹配不同的内容与产品推荐。不是发广告群，是有专业价值的内容 + 精准的产品推荐。
  4. 器械 × 课程交叉销售（3-12 个月）
    识别器械客户中的康复从业者 / 教练 / 治疗师，引导到运动康复师课程、线下课；反向为课程学员推荐配合使用的器械。这是本岗位最大的增量来源。
  5. 复购与耗材体系（6-12 个月）
    建立耗材复购提醒（电极片、气密袖套、按摩头等），设计"买机送耗材 → 转订阅"路径，提升客户生命周期价值。

我们希望你具备

  • 3 年以上客服团队管理 / 用户运营 / 私域运营经验，带过 5 人以上团队
  • 有从 0 到 1 搭建私域体系的完整经历（不是接手成熟体系，是自己搭过）
  • 能看懂数据：会用 Excel 做基础分析，能自己算转化漏斗、算 ROI，不依赖别人出报表
  • 有销售敏感度：能从客户一句话里判断真实需求和购买意向
  • 学习能力强：愿意花时间搞懂康复器械的专业知识（我们会有产品培训，但需要你自己钻）
  • 合规意识：我们做医疗器械，私域内容涉及医疗宣称有明确红线，不能乱说"治愈""根治"

加分项（有则更好）

  • 做过医疗器械 / 康复 / 健身 / 健康类目的私域
  • 有高客单价（5000 元以上）产品的销售或转化经验
  • 做过课程产品的销售（知识付费、职业培训）
  • 自己就是康复从业者 / 健身教练出身，转做运营

我们不合适的画像（先说清，省大家时间）

  • 只会做社群发券、裂变拉新的——我们要的是转化和复购，不是人数
  • 只做过低客单价快消品的——我们的决策链和话术完全不同
  • 纯执行、等指令的——这个岗要自己设计方案，我们只给方向和资源

常见写法（不建议）本版改法为什么
"负责私域流量池的搭建与运营" "把客服从成本中心改造成利润中心：服务过程中识别需求、引导下单" 前者是岗位描述，后者是价值主张。能吸引想做出成绩的人，也能筛掉混日子的

"提升客户复购率和满意度" "器械 × 课程交叉销售：识别器械客户中的康复从业者，引导到课程" 前者是结果，后者是具体抓手。写清抓手，候选人能判断自己会不会做
"有较强的沟通能力和团队协作精神" "有销售敏感度：能从客户一句话里判断真实需求和购买意向" 前者人人都会写，等于没写；后者是可验证的，面试能追问
没提合规 明确写"医械私域有合规红线" 我们是康复器械，这条必须提前筛。不懂合规的人进来会出事
没写"什么样的人不合适" 专门列了一段 能减少无效面试。对的人看到会更想来，不对的人自己就走了

四、KPI 怎么设计：三层漏斗，别一上来考 GMV

私域从 0 起步，第一年 GMV 不可能大。如果只考 GMV，他一定会去做"低客单快消品"冲量，那就偏离了你的初衷。

层指标为什么考这个建议目标
第一层
基础盘		 退款率（分平台）
客服响应时长
差评率		 这是纯利润。二类电商 31.41% 的退款率，降 5 个点就是实打实的钱 一类 17.8%→≤15%
二类 31.4%→≤25%
第二层
转化		 加微率
私域首单转化率
咨询→下单转化率		 这是体系是否搭起来的证明。加微率上不去，后面全是空的 加微率 ≥25%
首单转化 ≥15%
第三层
增量		 私域 GMV
复购率
器械→课程转化数		 这是最终结果，但第二年才该是重点 第一年不压硬指标
给方向性目标
建议的权重（第一年）：第一层 40% ｜ 第二层 40% ｜ 第三层 20%

第二年才把第三层提到 50%。第一年就压 GMV，会把一个好岗做成一个短视岗。

⚠ 目标值是我按现有数据给的建议区间，需要你按实际资源（客服人数、预算、平台）调整。

五、薪资结构建议

这是销售属性的岗，纯固定工资招不到能打的人；但纯提成也不行，因为第一年 GMV 小，人会走。

部分建议区间说明
底薪10–15K（郑州）负责人级。低于 10K 基本只能招到执行层
退款率改善奖按降低幅度阶梯这是最关键的一笔——降退款是纯利润，值得重奖
私域 GMV 提成按毛利额提建议按毛利而不是 GMV 提，避免他为了冲量卖低毛利品
课程转化奖按成交单数单独立项，因为这个动作是"额外"的，不奖就没人做
一个设计技巧：把"退款率改善"做成季度奖金而不是月度——因为退款率波动大，月度考核会让他为了数字做短期动作（比如卡退款审批，那会伤口碑）。

⚠ 薪资区间需你按公司薪酬体系核定，我这里只给结构和逻辑。

六、面试怎么问（5 个能筛人的问题）

Q1｜你搭私域的时候，第一批种子用户从哪来的？具体怎么加进来的？
✓ 好答案：说得出具体渠道、具体话术、具体转化率，甚至记得"第一个人是怎么加的"
✗ 坏答案：含糊说"通过平台导流""做了些活动"——说明没真做过
Q2｜你上一份工作里，退款率/退货率是多少？你做过什么把它降下来的？
✓ 好答案：能说出具体数字变化 + 具体动作（改详情页、加使用指导、调整客服话术）
✗ 坏答案：说"退款这块不归我管"——那这个岗他做不了
Q3｜假设一个客户来问"我妈腰椎间盘突出，能用你们的空气波吗"，你会怎么回？
✓ 好答案：先问清情况（严重程度/是否术后/医生建议），再给建议，并且知道什么话不能说（不诊断、不承诺疗效）
✗ 坏答案：直接说"能用，效果很好"——这是合规风险，也是专业不足
Q4｜如果让你从我们现有的客户里找课程客户，你会怎么找？
✓ 好答案：说得出筛选逻辑（买专业器械的、问专业问题的、复购耗材的），并能设计识别话术
✗ 坏答案：说"群发消息问有没有人想学"——这是最小白的做法
Q5｜你觉得私域最难的是什么？
✓ 好答案：说"内容供给"或"人效"或"客户分层"——说明真正干过
✗ 坏答案：说"加不到人"——把私域理解成拉人头

七、招人渠道：别只搜"私域运营"

搜索关键词会招到什么人建议
私域运营大量微商打法、社群裂变背景，不懂专业产品慎用
用户运营 / 会员运营更偏体系化，看数据，适合从 0 搭建首选
客服主管 / 客服经理懂服务流程，缺转化意识——需要面试重点考察首选
医疗器械 / 健康类目 运营懂行业、懂合规，稀缺但最对口最佳
课程顾问 / 教育行业销售主管转化能力强，需补私域体系能力可考虑
另外一个渠道值得试：康复行业的垂直社群、康复治疗师的职业群、健身教练群。从行业里找人转运营，比从运营里找人学行业快得多——尤其这个岗需要懂专业。
