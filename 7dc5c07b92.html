品 · 渠 · 人 · 钱
年度目标规划：从经营结论到人力承接

经营侧决定方向，人力侧决定能不能落下去

年度规划最容易错的一步，是起点。一上来就分指标，后面的编制和预算都在补前面的漏洞。

完整的链路是两段：先定做什么、怎么卖、要几个人、花多少钱，再把这四个结论翻译成部门重点工作、岗位指标、能力要求、人才动作。

前半段是经营侧，决定方向；后半段是人力侧，决定落不落得下去。只做前半段，规划停在预算表上；只做后半段，考核脱离经营实际。

整体结构

上篇 · 经营侧：定方向

  • 0
    目标值的来源三个基线交叉验证，先算可实现区间
  • 1
    品 · 资源投向划定主次，资源按级配
  • 2
    渠 · 规模路径评估渠道，识别单点依赖
  • 3
    人 · 编制依据由产出倒推，保住关键岗
  • 4
    钱 · 预算约束由产出倒推，设三条校验线

下篇 · 人力侧：接得住

  • 5
    部门 · 重点工作与核心指标经营语言翻译成职能语言
  • 6
    岗位 · 指标拆解与绩效年目标拆到月，指标落到人
  • 7
    岗位 · 画像与能力词典由岗位设置定要求，归并成标准
  • 8
    人才 · 招聘、盘点与排布标准用于进出，结论用于排布
顺序颠倒会产生两类后果。先定编制再定品，人员结构会先于业务判断被锁定，后续只能为已有的人安排工作。先定预算再定渠道，投入规模会沿用历史基数，新增投入缺少验证依据。
规划只做经营侧、不落到部门和岗位，年底考核只能依赖印象判断，绩效体系与经营结果脱钩。

上篇 · 经营侧：定方向

第 0 步 · 目标值的来源

0

目标值需要可追溯的推导过程

起点决定后续所有环节的假设
做什么
  1. 分别测算三个基线。历史趋势取近三年，避开峰值年；自身能力按现有产品、渠道、人力的实际产出测算；外部大盘看行业增速与主要竞争者的变化。
  2. 三项并列比对，找出偏差最大的一项。偏差本身是信息，说明某一项假设与实际不符。
  3. 以能力基线为起点，给出可实现区间。与目标值对照，差额定义为待攻坚项。
  4. 设置三档目标。下限、考核线、挑战线分别对应不同的资源配置和激励强度。
为什么
  1. 单一来源的目标缺少校准机制，外部条件变化时没有调整依据。
  2. 三档目标把"定多少"转化为"投多少、奖多少"，单档目标在期末只有完成或解释两种结果。
  3. 差额如果不被显性识别，就不会转化为动作，最终以"再努力一点"收场。
判断要点：目标值的可信度取决于推导链条的长度。链条越短，执行期可调整的余地越小。

第 1 步 · 品：资源投向

1

资源总量固定时，优先级只能通过数量体现

决定钱和人往哪里去
做什么
  1. 划定基底。同时满足出量、复购、毛利三项条件的品类，作为主力投入对象。
  2. 分级管理。主力、培育、淘汰三级，各级名额在规划阶段写定，不由执行期追加。
  3. 资源按级配。人力、预算、内容产能、渠道位置按级别分配，主力级获得明确倾斜。
  4. 单品建账。每个品建立四项记录：销量、毛利、退款、库存，作为去留依据。
为什么
  1. 资源总量固定，均摊等于取消优先级。被摊薄的不仅是预算，还有负责人的注意力。
  2. 分级如果不设名额上限，执行时所有品都会进入主力级，分级随之失效。
  3. 四项记录缺任何一项，该品都无法进入取舍，只能靠主观判断保留。
  4. 品类过多时，真正的问题不在库存金额，而在没有哪个品获得足够的投入强度。
判断要点：聚焦是否成立，可以用数量变化检验——被压缩了多少，被集中的资源有多少。

第 2 步 · 渠：规模路径

2

渠道能力能否脱离个别人存在，决定规模是否可复制

决定增长从哪里来
做什么
  1. 渠道评估三问。谁在承担销售、以什么方式承担、投入产出能否单独核算。
  2. 识别单点依赖。统计单个达人、单个链接、单个平台、单个客户在总量中的占比，占比过高的列入拆解对象。
  3. 投入产出分层。低于阈值的停止投入，区间内的观察并限量，高于阈值的放量，每档对应明确动作。
  4. 新渠道使用验证预算。达到验证标准后再给规模预算，验证标准在年初写定。
为什么
  1. 渠道能力如果依附于个别人或个别链接，规模不具备可复制性，人员变动会直接反映为业绩波动。
  2. 平均值会掩盖结构差异。同一账户内可能同时存在高回报单元和持续亏损单元，均值看起来正常。
  3. 以规模预算启动新渠道，等于用确定投入对赌未验证的模式，失败成本无法控制。
  4. 渠道选错时，后续投入的每一笔都在放大错误，且纠正成本随规模上升。
判断要点：渠道是否跑通，可以用脱离测试检验——换掉当前主要依赖对象，产出是否仍在可接受区间。

第 3 步 · 人：编制依据

3

编制的起点是产出，不是历史人数

决定目标能否被推动
做什么
  1. 由产出倒推编制。目标产出 ÷ 实际人均产出，得出底线人数，作为编制下限。
  2. 区分关键岗与辅助岗。关键岗优先保障，辅助岗按效率配置。
  3. 处理单点承担。某一模块由单人承担且占比过高时，规划中列明拆分节点与接替安排。
  4. 编制与目标按期对账。目标调整时，编制和薪酬包同步调整，不只调整目标。
为什么
  1. 编制一旦落为具体岗位，回收成本很高，因此起点必须是产出而非历史人数。
  2. 关键岗空缺造成的业务中断，代价高于人数超编。两者的风险量级不同。
  3. 人效偏差多数由品和渠引起。先调整人，容易误判问题所在。
  4. 目标下调和编制不下调，中间差额会转化为长期的效率损耗。
判断要点：编制方案是否成立，取决于人均产出用的是实际值还是目标值。用目标值倒推，人数会系统性偏少。

第 4 步 · 钱：预算约束

4

预算由产出倒推，并配置校验线

决定规模增长是否能留下利润
做什么
  1. 预算倒推。目标产出 → 单位投入 → 投入产出比校验，过线才给预算。
  2. 人力预算单列。目标 → 人数 → 薪酬包 → 薪酬占收入比，形成一条可核对的链。
  3. 设三条校验线：人效不低于上期、薪酬占收入比在区间内、投入产出比达标。三条同时满足才放行。
  4. 库存与在途单列清理目标。与营收目标并列，不并入费用项。
  5. 预留验证预算。用于新方向、新渠道、新品的小规模试错。
为什么
  1. 按上期基数加成的预算方式，会把历史低效固化为下期标准。
  2. 人力成本如果不在规划阶段锁定，全年处于被动追加状态，无法与目标同步调整。
  3. 只考核营收不考核费用率，规模增长可能与利润下降同时发生。
  4. 库存占用的是现金。只计入资产、不计入约束，资金压力会持续累积。
  5. 不预留验证预算，新方向只能借用存量预算，试错空间被挤压到零。
判断要点：预算是否可控，看三条校验线是否都有明确的责任人。没有责任人的校验线，执行期会被逐条绕开。

结构差异：增量来源不同，投法不同

上述四步是通用结构。具体资源投向，取决于规划期内的增量来源。三类路径的前提、投向与风险各不相同。

增量来源 前提条件 资源投向 主要风险
拓渠道
产品固定，可加渠道		 产品已验证、具备复购、价格带能支撑新渠道 渠道团队、渠道启动投入、平台运营能力 渠道间价格冲突、客户归属重复计算、原有渠道被分流
拓量
渠道固定，可提产出		 渠道已跑通，转化率、客单价、复购率可单独核算 转化与复购环节，销售人效提升 边际回报递减，规模增长与利润脱节；只看总量不看结构
拓新品
现有品类触及上限		 现有品类确实无空间，且具备开发与验证能力 研发与开品、测试预算、小批量试产 周期长、成功率低、试错成本转为库存；同时启动过多项目
三类可以叠加，但在同一规划期内通常只能以一类为主。它们的资源需求重叠，且存在先后依赖。同时推进多类，常见结果是每一类都停留在启动阶段。

下篇人力侧：接得住

经营结论落到预算之后，还有四个动作，才能让目标真正进入组织。这四个动作依次是：部门、岗位、能力、人才。

经营结论→部门重点工作→部门核心指标→岗位指标（年拆到月）→岗位绩效
岗位设置→岗位画像→能力素质词典→招聘标准/人才盘点→人员排布

两条支线在"绩效"和"能力"处汇合：一条决定"考什么"，一条决定"要什么样的人"。两者共同支撑盘点与排布。

第 5 步 · 部门：重点工作与核心指标

5

规划到部门这一层最容易断

经营语言翻译成职能语言
做什么
  1. 由品、渠、人、钱四项结论，推出各部门的年度重点工作。每部门控制在五项以内，按主次排序。
  2. 每项重点工作配核心指标。指标要有基线、目标值、统计口径三项要素，缺一项就不算定义清楚。
  3. 指标分两类。结果指标对经营结果负责，过程指标对关键动作负责，两类都要有。
  4. 与预算和编制对齐后再定稿。部门重点工作所需的钱和人，回过去核上篇的结论是否支撑得住。
为什么
  1. 上面是经营语言，下面是职能语言，中间没有翻译，就会出现"每个部门都知道目标，但不知道自己该干什么"。
  2. 重点工作超过五项，等于没有重点。部门精力会被摊开，每件事都推进一点。
  3. 只有结果指标会失控，因为过程不可见；只有过程指标会走形式，因为结果不负责。两类并存才能同时管住方向和动作。
  4. 部门重点工作和预算是两张皮时，执行期一定超支或搁置。
判断要点：部门重点工作是否成立，看它能否倒推回经营结论。倒推不回去的工作，属于部门自选动作，占用的是有限资源。

第 6 步 · 岗位：指标拆解与绩效

6

部门指标不拆到岗位，个人就没有抓手

年目标拆到月，指标落到人
做什么
  1. 按业务流程拆解。把部门指标沿业务流程拆到岗位，而不是平均分配。
  2. 每岗位确定三到五项考核指标。结果与过程搭配，权重体现优先级。
  3. 指标四项要素齐全。定义、算法、数据来源、考核周期，四项缺一项，考核就无法执行。
  4. 年目标拆到月。按季节性配置月度权重，不按十二个月均分。
  5. 形成岗位年度绩效指标表。每月可量化，偏差在月内可见。
为什么
  1. 部门指标只停在部门，考核只能考团队，个人没有责任落点，出现问题时找不到承担者。
  2. 指标超过五项，权重被摊薄，考核失去导向作用，员工会挑容易的做。
  3. 没有数据来源的指标，期末只能靠印象打分，绩效争议由此产生。
  4. 年拆月不是除以十二。业务有旺淡季，均分会让淡季永远完不成、旺季永远超额，考核信号失真。
  5. 月度可见，才有月度纠偏的可能。年度才看见的偏差，已经没有调整余地。
判断要点：岗位指标是否可用，检验方法是让该岗位的人复述一遍考核算法。复述不出来，说明指标没有落到可执行层面。

第 7 步 · 岗位：画像与能力词典

7

画像的依据是岗位设置，不是编制人数

由要求归并成公司级标准
做什么
  1. 基于岗位设置确定画像。每个岗位写清职责、产出、能力要求三项。编制决定要几个人，画像决定要什么样的人，两个维度分开。
  2. 岗位分级处理。关键岗做详细画像，通用岗共用能力模型，不逐岗展开。
  3. 归并成公司级词典。把各岗位的能力要求分层分类归并，形成统一的能力素质词典。
  4. 能力描述落到可观察行为。每条能力配行为锚点，写清什么表现算达标、什么表现算超出。
  5. 词典绑定两个应用场景。招聘评估表、盘点评价表，两张表的能力项直接取自词典。
为什么
  1. 编制是数量问题，画像是标准问题。混在一起谈，会导致"因为缺人所以降标准"。
  2. 全部岗位都做详细画像，成本高于收益，且多数通用岗的能力差异并不显著。
  3. 各岗位各写一套标准，招聘和盘点就无法横向比较，最终回到主观判断。
  4. 能力要求不落到行为，评估只能凭感觉。同一个"沟通能力强"，不同评估者的理解可以完全不同。
  5. 词典如果只用于存档，一年后无人使用。它必须同时服务招聘和盘点，才有维护的动力。这是词典失效最常见的原因。
判断要点：词典是否可用，看它能否直接生成一张招聘评估表和一张盘点评价表。生成不了，说明词典还停留在概念层。

第 8 步 · 人才：招聘、盘点与排布

8

盘点的目的是回答"明年这些事谁来做"

标准用于进出，结论用于排布
做什么
  1. 按词典制定招聘标准。评估表的能力项、面试问题、评分标准，三者与词典一一对应。
  2. 年度盘点用两个维度。绩效结果与能力评价，形成九宫格，区分出可用、待培养、需调整三类。
  3. 盘点产出三类结论。谁能接更大责任、谁需要补什么、谁在什么时间前需要替换。
  4. 人员排布分三类动作，判断标准不同：离职补缺，关键岗立即补，非关键岗先看能否合并；替换，绩效与能力双低且有接替人时执行；新增，在编制内且产出可验证时批准。
  5. 盘点和排布结果回写编制与预算。形成下一轮规划的输入。
为什么
  1. 招聘没有标准，只能靠试用期淘汰，纠错成本被推后且放大。
  2. 盘点如果只有评价没有结论，会开成评语会。评价本身不产生任何组织变化。
  3. 三类排布动作混在一起决策，容易出现"该换的没换、该并的又招"，编制越管越多。
  4. 盘点不回答"谁来做"，规划里的重点工作就没有责任人，落回规划表本身。
  5. 盘点结果不回写编制和预算，下一轮规划仍然从旧数据出发，形成循环偏差。
判断要点：盘点是否有效，看会后是否有人事动作发生。没有动作的盘点，只是年度例行工作。

人力部门在整条链上的位置

人力部门在整条链上有两个角色。上半段是校验者：确认品、渠、人、钱的假设互相对齐。下半段是承接者：把经营结论翻译成部门重点、岗位指标、能力标准和人才动作。

环节 人力部门的角色 判断依据
品 校验资源投向是否与分级一致 主力品相关的人员与预算投入，高于其他单元
渠 校验渠道产出是否存在单点依赖 关键人员变动不影响出量
人 校验编制依据是产出推算还是人数惯例 人均产出不低于上期，关键岗无空缺
钱 校验薪酬包是否随目标同步调整 薪酬占收入比在区间内，且变动可解释
部门 承接：重点工作收敛、指标定义完整 每项重点工作能倒推回经营结论，指标三要素齐全
岗位 承接：指标拆到岗、拆到月、要素齐全 岗位人员能复述自己的考核算法
能力 承接：画像、词典、两张应用表 词典能直接生成招聘评估表与盘点评价表
人才 承接：盘点有结论、排布有标准、结果回写 盘点后有人事动作，且回写进下一轮编制与预算
人力部门在这条链上的作用，是校验一致性、承接翻译，不是替代业务判断。

规划前的核对项

以下八项用于检验规划内部是否自洽。任一项无法回答，说明对应环节的推导尚未完成。

  1. 目标值由几个独立来源推算？来源少于两个，缺少校准机制。
  2. 本期的资源投向能否指向具体的品类或客群？无法指向具体对象，等于尚未选择。
