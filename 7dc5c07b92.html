品 · 渠 · 人 · 钱
年度目标规划的四段结构

目标值的来源、资源的投向、规模路径、编制依据与预算约束

年度规划最容易错的一步，是起点。一上来就分指标，后面的编制和预算都在补前面的漏洞。

目标规划的顺序是：品、渠、人、钱。品决定资源投向，渠决定规模路径，人决定执行速度，钱决定约束边界。

这个顺序本身比四者各自的做法更关键。顺序颠倒时，每一环都会变成对前一环的补救。

整体结构

  • 0
    目标值的来源三个基线交叉验证，先算可实现区间
  • 1
    品 · 资源投向划定主次，资源按级配
  • 2
    渠 · 规模路径评估渠道，识别单点依赖
  • 3
    人 · 编制依据由产出倒推，保住关键岗
  • 4
    钱 · 预算约束由产出倒推，设三条校验线
顺序颠倒会产生两类后果。先定编制再定品，人员结构会先于业务判断被锁定，后续只能为已有的人安排工作。先定预算再定渠道，投入规模会沿用历史基数，新增投入缺少验证依据。
目标先于品和渠确定，执行一旦偏离，就无法判断是目标本身有问题，还是路径没有走通。

第 0 步 · 目标值的来源

0

目标值需要可追溯的推导过程

起点决定后续所有环节的假设
做什么
  1. 分别测算三个基线。历史趋势取近三年，避开峰值年；自身能力按现有产品、渠道、人力的实际产出测算；外部大盘看行业增速与主要竞争者的变化。
  2. 三项并列比对，找出偏差最大的一项。偏差本身是信息，说明某一项假设与实际不符。
  3. 以能力基线为起点，给出可实现区间。与目标值对照，差额定义为待攻坚项。
  4. 设置三档目标。下限、考核线、挑战线分别对应不同的资源配置和激励强度。
为什么
  1. 单一来源的目标缺少校准机制，外部条件变化时没有调整依据。
  2. 三档目标把"定多少"转化为"投多少、奖多少"，单档目标在期末只有完成或解释两种结果。
  3. 差额如果不被显性识别，就不会转化为动作，最终以"再努力一点"收场。
判断要点：目标值的可信度取决于推导链条的长度。链条越短，执行期可调整的余地越小。

第 1 步 · 品：资源投向

1

资源总量固定时，优先级只能通过数量体现

决定钱和人往哪里去
做什么
  1. 划定基底。同时满足出量、复购、毛利三项条件的品类，作为主力投入对象。
  2. 分级管理。主力、培育、淘汰三级，各级名额在规划阶段写定，不由执行期追加。
  3. 资源按级配。人力、预算、内容产能、渠道位置按级别分配，主力级获得明确倾斜。
  4. 单品建账。每个品建立四项记录：销量、毛利、退款、库存，作为去留依据。
为什么
  1. 资源总量固定，均摊等于取消优先级。被摊薄的不仅是预算，还有负责人的注意力。
  2. 分级如果不设名额上限，执行时所有品都会进入主力级，分级随之失效。
  3. 四项记录缺任何一项，该品都无法进入取舍，只能靠主观判断保留。
  4. 品类过多时，真正的问题不在库存金额，而在没有哪个品获得足够的投入强度。
判断要点：聚焦是否成立，可以用数量变化检验——被压缩了多少，被集中的资源有多少。

第 2 步 · 渠：规模路径

2

渠道能力能否脱离个别人存在，决定规模是否可复制

决定增长从哪里来
做什么
  1. 渠道评估三问。谁在承担销售、以什么方式承担、投入产出能否单独核算。
  2. 识别单点依赖。统计单个达人、单个链接、单个平台、单个客户在总量中的占比，占比过高的列入拆解对象。
  3. 投入产出分层。低于阈值的停止投入，区间内的观察并限量，高于阈值的放量，每档对应明确动作。
  4. 新渠道使用验证预算。达到验证标准后再给规模预算，验证标准在年初写定。
为什么
  1. 渠道能力如果依附于个别人或个别链接，规模不具备可复制性，人员变动会直接反映为业绩波动。
  2. 平均值会掩盖结构差异。同一账户内可能同时存在高回报单元和持续亏损单元，均值看起来正常。
  3. 以规模预算启动新渠道，等于用确定投入对赌未验证的模式，失败成本无法控制。
  4. 渠道选错时，后续投入的每一笔都在放大错误，且纠正成本随规模上升。
判断要点：渠道是否跑通，可以用脱离测试检验——换掉当前主要依赖对象，产出是否仍在可接受区间。

第 3 步 · 人：编制依据

3

编制的起点是产出，不是历史人数

决定目标能否被推动
做什么
  1. 由产出倒推编制。目标产出 ÷ 实际人均产出，得出底线人数，作为编制下限。
  2. 区分关键岗与辅助岗。关键岗优先保障，辅助岗按效率配置。
  3. 处理单点承担。某一模块由单人承担且占比过高时，规划中列明拆分节点与接替安排。
  4. 编制与目标按期对账。目标调整时，编制和薪酬包同步调整，不只调整目标。
为什么
  1. 编制一旦落为具体岗位，回收成本很高，因此起点必须是产出而非历史人数。
  2. 关键岗空缺造成的业务中断，代价高于人数超编。两者的风险量级不同。
  3. 人效偏差多数由品和渠引起。先调整人，容易误判问题所在。
  4. 目标下调和编制不下调，中间差额会转化为长期的效率损耗。
判断要点：编制方案是否成立，取决于人均产出用的是实际值还是目标值。用目标值倒推，人数会系统性偏少。

第 4 步 · 钱：预算约束

4

预算由产出倒推，并配置校验线

决定规模增长是否能留下利润
做什么
  1. 预算倒推。目标产出 → 单位投入 → 投入产出比校验，过线才给预算。
  2. 人力预算单列。目标 → 人数 → 薪酬包 → 薪酬占收入比，形成一条可核对的链。
  3. 设三条校验线：人效不低于上期、薪酬占收入比在区间内、投入产出比达标。三条同时满足才放行。
  4. 库存与在途单列清理目标。与营收目标并列，不并入费用项。
  5. 预留验证预算。用于新方向、新渠道、新品的小规模试错。
为什么
  1. 按上期基数加成的预算方式，会把历史低效固化为下期标准。
  2. 人力成本如果不在规划阶段锁定，全年处于被动追加状态，无法与目标同步调整。
  3. 只考核营收不考核费用率，规模增长可能与利润下降同时发生。
  4. 库存占用的是现金。只计入资产、不计入约束，资金压力会持续累积。
  5. 不预留验证预算，新方向只能借用存量预算，试错空间被挤压到零。
判断要点：预算是否可控，看三条校验线是否都有明确的责任人。没有责任人的校验线，执行期会被逐条绕开。

结构差异：增量来源不同，投法不同

上述四步是通用结构。具体资源投向，取决于规划期内的增量来源。三类路径的前提、投向与风险各不相同。

增量来源 前提条件 资源投向 主要风险
拓渠道
产品固定，可加渠道		 产品已验证、具备复购、价格带能支撑新渠道 渠道团队、渠道启动投入、平台运营能力 渠道间价格冲突、客户归属重复计算、原有渠道被分流
拓量
渠道固定，可提产出		 渠道已跑通，转化率、客单价、复购率可单独核算 转化与复购环节，销售人效提升 边际回报递减，规模增长与利润脱节；只看总量不看结构
拓新品
现有品类触及上限		 现有品类确实无空间，且具备开发与验证能力 研发与开品、测试预算、小批量试产 周期长、成功率低、试错成本转为库存；同时启动过多项目
三类可以叠加，但在同一规划期内通常只能以一类为主。它们的资源需求重叠，且存在先后依赖。同时推进多类，常见结果是每一类都停留在启动阶段。

HR 在这条链上的位置

产品策略通常不由人力部门决定，但这条链上有一项工作只能由人力部门承担：校验各环节的假设是否互相对齐。

环节 校验动作 判断依据
品 主力品获得的人员与预算投入，是否与分级一致 主力品相关编制增速高于其他单元
渠 渠道产出是否依赖单一对象 关键人员变动不影响出量
人 编制依据是产出推算还是人数惯例 人均产出不低于上期，关键岗无空缺
钱 薪酬包是否随目标同步调整 薪酬占收入比在区间内，且变动可解释
人力部门在这条链上的作用，是校验一致性，不是替代业务判断。

规划前的核对项

以下六项用于检验规划内部是否自洽。任一项无法回答，说明对应环节的推导尚未完成。

  1. 目标值由几个独立来源推算？来源少于两个，缺少校准机制。
  2. 本期的资源投向能否指向具体的品类或客群？无法指向具体对象，等于尚未选择。
  3. 渠道产出是否依赖单一对象？依赖存在而规划中无拆解节点，规模不可复制。
  4. 编制依据是产出推算还是人数惯例？按惯例配置的编制，难以随目标下调。
  5. 薪酬占收入比的区间由谁设定和监控？没有责任人的指标，期末通常超线。
  6. 偏差达到什么程度触发调整，由谁决策？缺少触发线，复盘会退化为汇报会。
