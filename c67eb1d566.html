产品开发流程与判定线V1.02026-11-10 定稿

产品经理流程SOP

八段活，五道门。每一段写清干什么、交什么、什么算过。

怎么读

从上往下走，一个圆点是一段活，红框圆点是门。

过线是硬条件，全绿才能进下一段。有一条红，停在这儿。

括号里的 T-01 到 T-08 是对应的表单，见文末。

P1

品类洞察与立项 这一步决定做不做

定这个品做不做、打哪一段价格带。

要干的活
  • 按价格带切市场，每段找 3 个在卖的当参照
  • 扒竞品差评，分类、算占比，标出能不能改
  • 算成本、定价、毛利，算出回本要卖多少台
  • 把资质、专利、供应链、平台四类风险摆出来，各给一条对策
交出来
品类立项报告 T-02竞品矩阵成本测算表
过线
  • 竞品 ≥15 个，覆盖 ≥4 个价格带，每带 ≥3 个
  • 评价样本 ≥2000 条，重点竞品每个 TOP3 ≥300 条
  • 差评归因 ≥8 类，每类有占比和“能不能改”
  • 机会点 ≥5 条，每条一句“为什么是我们”
  • 成本、定价、毛利、回本月销四项误差 ≤10%
  • 每个结论能指到数据源，指不到的删掉
G1
立项门卡在立项前

要全绿：机会点排序、盈亏测算、“为什么是我们”、四类风险有对策。

不过门：不做，或者补数据再来。后面一分钱不花。

签：产品负责人、分管领导

P2

产品定义与方案 把话写死

写成能开模、能报价、能判验收的规格。

要干的活
  • 先定自研还是 OEM，写清为什么选这个
  • 性能、使用条件、寿命、安全、标识五类写死
  • 关键器件定型号定供应商，每家留一个备选
  • BOM 逐件列，至少 3 家比价，问清有没有给同行供货
交出来
产品规格书 T-03BOM 成本表供应商评估表
过线
  • 规格书“待定”“以实物为准”数量为 0
  • 五类内容齐全，缺一类不许冻结
  • BOM 没有“其他 / 杂项”兜底行
  • 实际成本 ≤ 目标成本 ×1.05
  • 供应商 ≥3 家，六项评估齐全
  • 关键件不是独家，或已写明二供
G2
方案冻结门卡在开模、下单前

要全绿：规格零待定、BOM 逐件列全、成本达标、供应商三家以上。

不过门：不开模，不下单。这里一停，省的是模具费和首批货款。

签：产品负责人、供应链

P3

打样验证 三轮，一轮比一轮近量产

用样机把规格书上的每一条验证一遍。

要干的活
  • 第一轮手工样：看装不装得上、标识读不读得清
  • 第二轮开模首件：看模具、公差、装配
  • 第三轮小批试产：看批次一致性、可靠性、寿命
  • 每轮出报告，问题清单跟到关闭，不闭合不带进下一轮
交出来
样机测试报告 T-04（三轮）问题清单
过线
  • 样机数：手工 ≥5 台、开模首件 ≥10 台、小批 ≥30 台
  • 关键指标 100% 达标，不接受“基本达标”
  • 一致性：离散度 ≤ 标称公差的一半
  • 一次装配合格率 ≥95%
  • 寿命按品类定次数，没定的不放行
  • 小批样机必须是量产工艺做的，手工件不许送检
G3
送检门卡在送检前

要全绿：三轮全项过、一致性达标、样机是量产工艺做的。

不过门：不送检。检验费和三个月时间，别浪费在手工件上。

签：产品经理、质量、法规

P4

资质与合规 先把证算进时间

该拿的证拿到，证上的型号和量产的型号对得上。

要干的活
  • 先查这个品类要什么：注册证、认证、备案，还是只做检测
  • 写技术要求，每个指标配一个检验方法
  • 送有资质的机构检验，留报告原件
  • 建台账：谁在办、什么时候启动、卡住哪个节点
交出来
注册证 / 认证 / 检测报告资质合规台账 T-05
过线
  • 证上型号规格与量产型号 完全一致
  • 每个性能指标都有检验方法，无空白项
  • 说明书、证照、技术要求 三方零冲突
  • 办理周期已倒排进上市计划，留了缓冲
P5

量产与入仓 样机能不能复制成货

把一台样机变成一万台一样的货。

要干的活
  • 试产三批，每批不少于 100 台，看良率掉在哪
  • 定来料、过程、出厂三层检验
  • 盯齐套，齐了才下单，不边到边做
  • 首批全检，留批记录，能追到料和工位
交出来
试产报告三层检验标准批记录
过线
  • 一次交检合格率 ≥98%
  • 关键指标过程能力 Cpk ≥1.33
  • 物料齐套率 100%
  • 首批入仓 ≤ 上市日 -15 天
  • 换供应商换批次，先留首件对比再投产
G4
量产放行门卡在大货前

要全绿：证照到手、三批试产合格、三层检验标准落地。

不过门：不下大货单。这里松口，压的是库存和现金。

签：产品、质量、供应链

P6

包装与合规物料 最容易挨罚的一段

包装、说明书、标签、宣传素材，一个字都不能错。

要干的活
  • 四件套一起做，别分开做，分开必打架
  • 法务或法规逐条过文案
  • 说明书、证照、技术要求三方逐条比对
  • 要审查的素材先送审，拿到批文再投放
交出来
包装稿说明书 / 标签三方比对表 T-06审查批文
过线
  • 标签缺项 = 0，按品类清单逐项打勾
  • 三方比对 零冲突
  • 功效或性能宣称 100% 在核准范围内
  • 包装打样 ≤3 轮定稿，每轮有修改对照
P7

上市与营销 能上架、能卖、能算账

物料、资质、备货、话术，四样齐了才开卖。

要干的活
  • 上市方案倒排到周，不到月
  • 详情页、主图、短视频、脚本一起过
  • 平台资质先备齐，再谈上架时间
  • 给销售和客服培训口径：一句话卖点，三句异议怎么答
交出来
上市方案 T-07详情页 / 素材平台资质包
过线
  • 首发备货 ≥ 首月预测 ×1.5
  • 卖点 ≤5 条，每条对应一个可验证的参数
  • 平台资质 齐全，无缺项
  • 首周按日更新销量、退货率、差评关键词
  • 上市 30 天退货率 ≤5%
G5
上市放行门卡在上架前

要全绿：包装物料过审、素材有批文、平台资质齐全、备货到位。

不过门：不上架。证没到手先投流，罚的比赚的多。

签：产品、电商、法规

P8

上市后运营与迭代 看账，做决定

每月一次账，每个异常给一个结论：改、降、换、停。

要干的活
  • 次月 10 日前出月度经营表，数据下钻到 SKU
  • 差评前五逐条归因，指定整改人
  • 盯竞品价格和上新节奏
  • 出迭代计划，作为下一轮 P1 的输入
交出来
月度经营表 T-08整改单决策单
触发线
  • 退货率 >5% 连续两个月 → 启动整改
  • 单条差评占前五 >20% → 立项解决
  • 竞品同规格低 >15% → 出降本或调整方案
  • 月销连跌 3 个月 >20% → 换代或退市评估
  • 经营表次月 10 日前出，能下钻到 SKU

按品类查：要什么证、多久

选品时先看这一栏。周期算不进上市时间的品，别接。

品类通常要什么大概多久卡在哪
普通消费品第三方检测报告2–4 周执行标准选错，抽查下架
小家电 / 电子强制认证（目录内）1–3 个月目录判断错，卖一半被要求下架
化妆品备案或注册 + 检测1–3 个月功效宣称超范围，备案被驳
食品生产许可 + 执行标准2–4 个月代工厂资质不覆盖你的品类
二类医疗器械注册证6–10 个月发补一次，多两三个月
三类医疗器械注册证 + 临床12–24 个月临床机构排期，不可控

从上市日往回推

以目标上市日记 T。按二类器械的节奏排，普通品类把前六个月砍掉。

节点要发生的事谁在等谁
T-12 月规格冻结，样机就绪，送检供应商等规格冻结
T-10 月检验完成，出报告检验机构排期
T-8 月提交申报资料质量，决定要不要发补
T-6 月审评，可能发补发补一次加 2–3 个月
T-5 月拿证拿证才敢约大货
T-4 月备料，试产三批齐套率
T-3 月包装定稿，素材送审审查周期
T-2 月大货生产产线排期
T-1 月入仓，详情页就位电商设计排期
T上市—
